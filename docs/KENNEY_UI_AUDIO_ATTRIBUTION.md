# Kenney UI Audio alpha sounds

Source: https://kenney.nl/assets/ui-audio

Repository mirror used for this alpha import: https://github.com/Calinou/kenney-ui-audio

License: Creative Commons Zero, CC0. A copy of the source license note is stored at `unity-client/Assets/Resources/Audio/Battle/Whimsy/KENNEY_UI_AUDIO_LICENSE.txt`.

These clips are used for softer, more whimsical alpha board feedback. They are still placeholders and can be replaced by commissioned Appreciators audio later without changing gameplay code.

## Board action mapping

| Board action | Clip |
| --- | --- |
| Select card | `Whimsy/click1.wav` |
| Invalid action | `Whimsy/click4.wav` |
| Place card | `Whimsy/switch7.wav` |
| Card attacks | `Whimsy/mouseclick1.wav` |
| Card takes damage | `Whimsy/switch13.wav` |
| Card is defeated | `Whimsy/switch28.wav` |
| Turn produces Art/Blockchain shards | `Whimsy/switch12.wav` |
| Spend a shard | `Whimsy/switch14.wav` |
| Apply Community ward | `Whimsy/rollover2.wav` |
| Apply Community rally | `Whimsy/rollover3.wav` |
| End turn | `Whimsy/switch26.wav` |
